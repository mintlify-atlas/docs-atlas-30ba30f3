---
title: "Quickstart: Install and run Hermes Web UI"
description: "Install Hermes Web UI globally via npm or a one-line setup script, then start the server on port 8648 and open the dashboard in your browser."
---

Hermes Web UI ships as an npm package with a CLI that manages the server as a background daemon. The quickest path is a single `npm install` followed by `hermes-web-ui start`, which launches the BFF server, auto-configures the Hermes gateway connection, and opens the dashboard in your default browser.

## Install

<Tabs>
  <Tab title="npm (recommended)">
    Install the package globally, then start the server:

    ```bash
    npm install -g hermes-web-ui
    hermes-web-ui start
    ```

    The server starts on **http://localhost:8648** by default.
  </Tab>
  <Tab title="One-line setup script">
    The setup script auto-detects your OS and installs Node.js if it is missing, then installs `hermes-web-ui`. Supported on Debian, Ubuntu, and macOS:

    ```bash
    bash <(curl -fsSL https://raw.githubusercontent.com/EKKOLearnAI/hermes-web-ui/main/scripts/setup.sh)
    ```

    After the script completes, run:

    ```bash
    hermes-web-ui start
    ```
  </Tab>
  <Tab title="WSL">
    Run the setup script inside your WSL environment:

    ```bash
    bash <(curl -fsSL https://raw.githubusercontent.com/EKKOLearnAI/hermes-web-ui/main/scripts/setup.sh)
    hermes-web-ui start
    ```

    <Note>
      WSL auto-detects the environment and uses `hermes gateway run` for background gateway startup instead of launchd or systemd.
    </Note>
  </Tab>
</Tabs>

## What happens on startup

When you run `hermes-web-ui start`, the CLI:

<Steps>
  <Step title="Resolves port conflicts">
    Checks whether port 8648 (or your custom port) is already in use and kills any stale processes occupying it.
  </Step>
  <Step title="Generates an auth token">
    Creates a random 64-character hex token and writes it to `~/.hermes-web-ui/.token` with mode `0600`. The token is passed as a `Bearer` header for all API requests. You can override this with the `AUTH_TOKEN` environment variable, or disable auth entirely with `AUTH_DISABLED=1`.
  </Step>
  <Step title="Validates and patches config">
    Reads `~/.hermes/config.yaml`, fills in missing `api_server` fields (host, port, CORS), backs up the original to `config.yaml.bak`, and writes the updated config.
  </Step>
  <Step title="Ensures the gateway is running">
    Checks the Hermes gateway health endpoint at `http://127.0.0.1:8642/health`. If the gateway is not running, the BFF starts it in the background automatically.
  </Step>
  <Step title="Polls the health endpoint and opens the browser">
    Polls `http://127.0.0.1:{port}/health` every 500 ms for up to 30 seconds. Once the server responds with a 200, it prints the dashboard URL with the auth token embedded and opens it in your default browser.
  </Step>
</Steps>

## CLI reference

| Command | Description |
|---|---|
| `hermes-web-ui start` | Start the server in background (daemon mode) |
| `hermes-web-ui start --port 9000` | Start on a custom port |
| `hermes-web-ui stop` | Stop the background process |
| `hermes-web-ui restart` | Restart the background process |
| `hermes-web-ui status` | Check whether the server is running |
| `hermes-web-ui update` | Update to the latest version and restart |
| `hermes-web-ui -v` | Print the installed version |
| `hermes-web-ui -h` | Print the help message |

### Custom port

Pass `--port` to start the server on a port other than the default 8648:

```bash
hermes-web-ui start --port 9000
```

The port value is also accepted as a positional argument:

```bash
hermes-web-ui start 9000
```

## Daemon logs

The server runs as a detached background process. Its output is written to `~/.hermes-web-ui/server.log`. If the server fails to start, check this file first:

```bash
cat ~/.hermes-web-ui/server.log
```

<Warning>
  The PID file at `~/.hermes-web-ui/server.pid` tracks the running process. Do not delete it manually while the server is running — this breaks the `stop`, `restart`, and `status` commands.
</Warning>
