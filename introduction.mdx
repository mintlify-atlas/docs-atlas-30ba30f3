Hermes Web UI is a full-featured web dashboard for [Hermes Agent](https://github.com/NousResearch/hermes-agent), a multi-platform AI chat system. It runs as a local BFF (Backend for Frontend) server on port 8648 and gives you a clean, responsive interface to manage chat sessions, configure platform channels, monitor usage and costs, schedule cron jobs, browse skills, and access an integrated web terminal — all without leaving your browser.

## Prerequisites

Before installing Hermes Web UI, make sure you have the following:

- **Node.js 18 or later** — the server and CLI require a modern Node.js runtime.
- **Hermes Agent** — the `hermes` CLI must be installed and available on your `$PATH`. The BFF server wraps Hermes CLI commands for session management, log reading, and gateway control.

<Note>
  Hermes Web UI auto-detects whether the Hermes gateway is running and starts it in the background if needed. You do not need to start the gateway manually before launching the web UI.
</Note>
