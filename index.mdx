Hermes Web UI gives you a clean, responsive browser interface for [Hermes Agent](https://github.com/EKKOLearnAI/hermes-web-ui) — the multi-platform AI assistant. From one dashboard you can hold conversations, connect Telegram, Discord, Slack, WhatsApp and five other messaging platforms, set up scheduled AI tasks, and track token usage and costs over time.

## Get up and running

<Steps>
  <Step title="Install Hermes Web UI">
    Install globally from npm — no build step required:

    ```bash
    npm install -g hermes-web-ui
    ```
  </Step>
  <Step title="Start the server">
    Launch the dashboard server in the background:

    ```bash
    hermes-web-ui start
    ```

    The server starts on port **8648** by default. Your browser opens automatically with an authentication token pre-filled in the URL.
  </Step>
  <Step title="Connect your AI agent">
    Hermes Web UI proxies to a running Hermes Agent gateway on `localhost:8642`. If the gateway is not running, the dashboard starts it automatically on first launch.
  </Step>
  <Step title="Start chatting">
    Navigate to the **Chat** tab in the sidebar. Select a model from the global model picker and send your first message. Sessions are saved automatically and can be renamed, grouped, or deleted at any time.
  </Step>
</Steps>
